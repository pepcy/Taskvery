# Task Manager — GitHub-inspired Flutter UI

Local-first Android task manager. No login, account or backend required.

## Features
- GitHub-inspired dark/light responsive shell
- Dashboard, Tasks/Issues, task detail, Projects, Kanban, Milestones, Labels-ready data model, Settings
- Local persistence with SharedPreferences
- Demo workspace seeded on first launch
- Theme mode + accent color
- JSON model ready for export/import integration
- Local notifications service initialized with Android notification channel
